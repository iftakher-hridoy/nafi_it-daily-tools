# Contributing to VMS – Daily Work Tools

Thank you for helping improve this project. This is a small, single-file open-source project — please keep contributions simple and focused.

## How to contribute

1. **Fork** the repository on GitHub.
2. **Create a branch** for your change:
   ```bash
   git checkout -b my-improvement
   ```
3. **Make your change in `index.html` only.** The whole website is one file — please do not split it into many files, so it stays easy to upload to GitHub Pages.
4. **Test it** by opening `index.html` in a browser (Chrome / Edge / Firefox). Check desktop and mobile width.
5. **Open a Pull Request** and describe:
   - What changed
   - Why it is needed
   - How you tested it

## What we welcome

- Bug fixes (wrong calculation, broken button, layout issue)
- New useful tools that fit the dashboard
- Bangla / English language improvements
- Better mobile layout and accessibility
- Clearer labels and help text

## What to avoid

- Adding a backend, server, or paid service — this project is static by design.
- Adding trackers or sending user data anywhere.
- Large libraries for a small feature — prefer small, plain JavaScript where possible.

## Reporting a bug

Open an Issue and include:

- What you clicked / typed
- What you expected to happen
- What actually happened
- Your browser and device (for example: Chrome on Android)

## Code style

- Keep the dark navy grid design.
- Keep labels short and clear, in English, with Bangla where it helps users.
- Do not hard-code anyone's personal data (names, duty times, file-server addresses) into the page — those belong in the user's own entries, not in the shared code.

Thank you!
