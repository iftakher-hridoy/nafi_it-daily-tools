Network Diagnostic Tools

DNS lookup, domain IP, website response test and browser-side ping — plus your local network information.

Traceroute note: a web page cannot run a real system traceroute — browsers have no access to ICMP/TTL routing. The checks above give you the DNS answers and real response timing instead, which cover most day-to-day questions. For a true traceroute, run tracert (Windows) or traceroute (Mac/Linux) in a terminal.

Network information (this device)

Local IP is detected through WebRTC and may show a private 192.168.x.x / 10.x.x.x address. Gateway and Wi-Fi details (SSID, signal) are not exposed to web pages by any browser — those live in your router/OS settings.

Publish this site free on GitHub Pages

This whole website is one single file — index.html — so hosting it takes about five minutes, and then you can open it from anywhere.

Download this exact page as a ready-to-upload index.html. To make a zip: put the file in a folder, right-click the folder → Compress / Send to → Compressed (zipped) folder, then unzip it inside your GitHub repo upload.
  1. Create a GitHub account (free) at github.com, if you don't have one.
  2. Create a new repository: click + → New repository. Name it e.g. vms-daily-work-tools, keep it Public, and create it.
  3. Upload the file: in the new repo, click uploading an existing file, choose the downloaded index.html, and Commit changes. The file must sit in the top level of the repo and be named exactly index.html.
  4. Turn on GitHub Pages: repo → Settings → Pages → under “Build and deployment”, Source = Deploy from a branch, Branch = main / / (root) → Save.
  5. Wait 1–2 minutes, then your site is live at https://YOUR-USERNAME.github.io/vms-daily-work-tools/ — open it from any phone or PC, anywhere. Bookmark it or add it to your home screen.
  6. To update later: upload a new index.html over the old one (same steps) — the site updates within a minute or two.
Good to know: duty log and roster entries are stored in each browser's own storage. That means entries you type on your phone stay on that phone's browser — they do not sync between devices. Use the CSV export buttons to move a month's data between devices.
